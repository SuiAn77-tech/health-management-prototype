# 健康管理移动端交互原型

这是基于「健康管理」Figma 文件 6 个真实页面实现的无依赖移动端原型。直接以内联 SVG 渲染原稿的矢量文字、图标和布局，并在原有 SVG 控件内更新交互状态，不再使用整页 PNG 背景。入口文件是 `index.html`，页面状态和交互在 `app.js`，视觉样式在 `styles.css`。

## 运行

在当前目录运行 `node server.cjs`，然后访问 <http://localhost:4173>。页面通过 fetch 加载 SVG，需要使用 HTTP 服务。

用户原始 SVG 保留在 `figma-source`。运行 `node scripts/prepare-vectors.cjs` 可重新生成 `assets/screens`：裁掉导出画板外侧留白，保留设计内的 16px 边距，提取原图照片且不重新编码。页面按手机宽度等比适配。

## 已实现

- 概览首页：待打卡 / 已打卡两种状态、趋势卡片、环境微诱因、记录快捷入口
- 今日习惯与诱因打卡：周期开关、饮食 / 体感选择、水量加减、局部照片上传、完成后同步首页状态
- AI 诱因关联分析：高危诱因筛选、关联曲线、贡献排行、周期预警和调理方案入口
- 皮肤影像日志：前后对比、分区评分、影像时间轴和定点照片入口
- 医学基准与个性化调理方案：7 日修护计划、成分安全名单、报告导出反馈
- 底部四栏导航和 toast 反馈，打卡状态保存到浏览器 `localStorage`

饮食与皮肤体感统一使用原稿的粉色实心圆加白色对钩选中态、灰色空心圆未选中态。诱因筛选切换只改变颜色，不改变尺寸。定点照片与替换上传的图片共用 19px 圆角。报告导出为提示演示，照片仅在当前浏览器会话内显示。
